# P1-T6: Discovery UI

Same-origin static TypeScript UI: collection/mode/exact-field filters, source
snippets, structured details, three-package comparison, metadata verification,
provenance/evidence disclosures and responsive layouts. Text uses DOM textContent;
no package HTML execution. Organization avatars are identification assets only.

Validation: npm run build passed; npm run test:e2e: 3 passed. Search, detail,
comparison and live local verification checked at 1440px and 390px. Screenshots
were visually inspected; no document horizontal overflow or broken images.
Mobile comparison is intentionally horizontally scrollable inside the dialog.
Hostile text test passed. Local screenshots are in .data/screenshots/.

npm TLS resets were bypassed by curl retrieval plus SHA-512 verification against
the published Lucide release metadata, then cache-only npm installation. The
lockfile retains the upstream tarball URL and integrity, not machine-local paths.

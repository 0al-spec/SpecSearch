# P1-T4: Local embedding adapters

Ollama and LM Studio batch adapters, Nomic role prefixes, bounded UTF-8 chunks,
normalized means, finite/dimension checks, content-addressed document cache,
model fingerprints and drift checks. Queries are not cached or logged.
LM Studio requires the operator's served GGUF artifact path for its fingerprint;
the API alone cannot attest that the configured file is the served artifact.

Validation: 16 tests passed, 1 optional corpus skip; Ruff passed.
Both live adapters generated document and Russian-query vectors of dimension
768. One smoke-pair cosine: Ollama .473622, LM Studio .476991. This verifies
transport only, not retrieval quality or superiority. Ollama F16 and LM Q4_K_M
remain separate identities. No inference used a generation model.
